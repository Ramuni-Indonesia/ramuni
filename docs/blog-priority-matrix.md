# Matriks Prioritas Konten Blog RAMUNI

Dokumen ini adalah sumber keputusan eksekusi konten. Nilai deliveryPriority di frontmatter setiap artikel harus selalu sama dengan tabel di bawah; tag ini hanya mengatur urutan pekerjaan, bukan jaminan ranking.

## Definisi tag

| Tag | Arti | Kapan dikerjakan |
| --- | --- | --- |
| P0 | Dampak dan urgensi tertinggi | Sinyal GSC sudah ada atau halaman adalah cornerstone/core cluster; refresh sebelum backlog lain. |
| P1 | Peluang berikutnya | Posisi GSC 11-35, artikel pendukung langsung, atau halaman yang menguatkan jalur ke P0. |
| P2 | Pemeliharaan dan cakupan | Long-tail, edukasi pendukung, AI/data, atau industri; kerjakan setelah P0/P1 atau saat ada sinyal baru. |

## Cara memakai

- Kerjakan P0 per cluster: relevansi intent, internal link masuk/keluar, canonical, structured data, UX mobile, dan dateModified.
- Setelah satu halaman P0 selesai, gunakan halaman itu sebagai sumber internal link untuk P1 yang relevan; jangan membuat artikel baru jika intent sudah terjawab.
- P1 dan P2 tetap indexable bila memenuhi standar kualitas. Prioritas tidak mengubah draft, noindex, canonical, atau sitemap.
- Jika GSC menunjukkan dua URL untuk query yang sama, pilih satu URL utama dan ubah halaman lain sesuai intent sebelum menambah konten.
