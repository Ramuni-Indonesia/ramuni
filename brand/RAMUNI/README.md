# RAMUNI Final Brand Kit

Approved direction: Lipat Arah. RAMU is navy and NI is turmeric yellow.

## Ready-to-use variants

- Mark only, wordmark only, horizontal lockup, and stacked lockup.
- Color, monochrome, and all-white/reverse versions.
- SVG masters plus transparent PNG and WebP exports.
- Transparent export sizes: 256, 512, 1024, and 2048 px wide.
- Transparent favicon sizes: 16, 24, 32, 48, 64, 96, 128, 180, 192, 256, and 512 px.
- JPEG copies use approved solid brand backgrounds because JPEG cannot store transparency.

Use `exports/ASSET-MANIFEST.csv` to find every format, size, variant, and transparency status. Use the PDF and Markdown brand guidelines for implementation.
